# 같은 카메라에서 측정한 렌더링 비용

v32와 리마스터 값이 순서대로 표시돼. Linux Chromium, SwiftShader 소프트웨어 WebGL 2, 720 × 450, DPR 1, 높은 품질, 동일한 황혼 환경이야. 각 구역은 새 브라우저 컨텍스트에서 빌드 파일을 로컬 응답으로 공급하고 인트로를 건너뛰었어. 정상 게임 루프에서 카메라를 고정하고 여섯 프레임을 보낸 뒤 이어지는 20개 프레임 간격으로 계산했어. 드로 콜과 삼각형은 마지막 프레임의 Three.js 카운터야. 힙은 JS가 쓰는 메모리이고 준비 시간은 페이지 시작부터 첫 조작 가능 프레임까지야. 네트워크 다운로드 시간과 GPU 메모리는 별도로 측정하지 않았어. 구역마다 한 번 측정해서 AI 상태·프로세스 부하·GC에 따른 차이가 있어.
