# Estuary landscape

Grass Path 3 by Rob Tuytel, [Poly Haven](https://polyhaven.com/a/grass_path_3), [CC0 1.0](https://polyhaven.com/license). The 1K diffuse, OpenGL normal and roughness JPEGs were verified against the Poly Haven file API MD5 values, resized to 512 × 512 and encoded as WebP. The three maps are shared between the garden and outer embankments. The landscaping, buildings, signs and moving doors are original Harborline geometry. The park trees also reuse the licensed [street foliage](../street/CREDITS.md).
